# เอกสาร Pitching นวัตกรรม — PEA Estimation AI Pro 2026

> PEA Inno MOVE 2026 | กฟจ.นครพนom  
> อัปเดต: 2026-06-13

---

## Elevator Pitch (30 วินาที)

> "PEA Estimation AI Pro คือระบบประมาณการพัสดุไฟฟ้า กฟภ. ที่ใช้ AI อ่าน BOM จากรูปถ่าย คำนวณงบ 4 ประเภทอัตโนมัติ และ **สำรวจหน้างานปักหมุดบนแผนที่** — รองรับ MV/LV ครบ รวม Guy, Surge และ Grounding ตามมาตรฐาน กฟภ. สร้างรายการประมาณการได้ในครั้งเดียว"

---

## ปัญหา (Problem)

| Pain Point | ผลกระทบ |
|------------|---------|
| พิมพ์รหัสพัสดุจาก BOM ด้วยมือ | 30–60 นาที/โครงการ |
| รหัสพัสดุซับซ้อน (or/slash/range) | พิมพ์ผิด → ประมาณการผิด |
| สูตรงบ 4 ประเภท คำนวณเอง | เสี่ยงคำนวณผิด |
| สำรวจหน้างานแล้วกลับมาทำประมาณการซ้ำ | เสียเวลา 2 รอบ |
| ลืม Guy/Surge ที่เสา end/curve | ประมาณการไม่ครบมาตรฐาน |
| ไม่มีหลักฐานเส้นทางสำรวจ | กลับมาดูไม่รู้ว่าปักจากไหน |

---

## โซลูชัน (Solution)

### 1. AI Scan BOM
- ถ่ายรูป/PDF → Gemini อ่านรหัส + จำนวน
- Human-in-the-loop ตรวจก่อนบันทึก

### 2. ปุ่มทางลัดพัสดุ
- หม้อแปลง / เสา / สายไฟ — กดปุ๊บได้เลย

### 3. โหมดสำรวจหน้างาน ⭐ จุดเด่น
- เลือก **MV/LV + 1P/3P** ตามระบบจำหน่ายจริง
- ปักหมุด + วางเสาตาม Span + โค้ง OSRM
- **SET มาตรฐาน กฟภ.** — หัวเสา, OHGW, Guy, Surge, Grounding
- เสาต้นท้าย / เข้า-ออกโค้ง → ระบบเติม spec อัตโนมัติ
- LV: Surge ทุก 400 ม. ตามเส้นทาง
- จับภาพแผนที่ + **กล่องสรุปเสา** + พิกัด เก็บในประวัติ
- **Export KML** → นำเข้า GIS ต่อได้
- **ตาราง SET** — จัดกลุ่มพัสดุตามชุด SET กรอกระบบหน่วยงานง่าย
- สร้าง BOM → นำเข้างบทันที

---

## Demo Flow (แนะนำ 5–7 นาที)

1. **สำรวจ — เลือกระบบ** — MV 1P → ตั้ง Default → เริ่มสำรวจ
2. **ปักหมุด** — หมุด 0 + หัวเสาเริ่ม → ปลายทาง + เข้า/ออกโค้ง
3. **สำรวจเสร็จ** — กล่องสรุปเสา + export KML + ตรวจเสาพิเศษ (Guy, DE head)
4. **สร้างรายการ** — BOM expand SET 72 ชุด
5. **บันทึก** — ไฟล์ + พิกัด + SET summary
6. **ประวัติ** — แผนที่ + SET grouping + Export PDF

| ระบบเดิม | PEA Estimation AI Pro |
|----------|----------------------|
