### สไลด์ 3: โซลูชัน (Solution)

**จาก BOM สู่ยอดประมาณการใน 3 ขั้นตอน**

```
📸 ถ่ายรูป BOM  →  🤖 AI อ่านอัตโนมัติ  →  ✅ ตรวจสอบ + คำนวณงบ
```

**3 หลักการออกแบบ:**
1. **AI ทำงานหนัก** — อ่านรหัสพัสดุและจำนวนจาก BOM
2. **มนุษย์ตัดสินใจ** — เลือกค่าแรงและยืนยันข้อมูล (Human-in-the-Loop)
3. **สูตรถูกต้อง 100%** — คำนวณตามนโยบายงบ กฟภ. ทุกประเภท

## 3. คำถามที่กรรมการอาจถาม (Q&A Prep)

### Q: AI อ่าน BOM แม่นแค่ไหน?

**A:** ใช้ Gemini 2.5 Flash พร้อม prompt engineering เฉพาะ BOM กฟภ. — สกัดรหัสพัสดุทั้งก้อนและจำนวนจากคอลัมน์ REQ'D ช่อง I เท่านั้น มี AI Review Queue ให้ผู้ใช้ตรวจสอบก่อนนำเข้าทุกครั้ง (Human-in-the-Loop) ลดความเสี่ยงผิดพลาด

### Q: ข้อมูลปลอดภัยไหม?

**A:** ปัจจุบันใช้ password สำหรับแก้ไข/ลบ + เก็บใน Google Workspace ของ กฟภ. แผน Phase 2 จะเพิ่ม security hardening: ย้าย API key ไป Script Properties, hash password, และพิจารณา Google OAuth

### Q: ต้นทุนเท่าไหร่?

**A:** ~0 บาท/เดือน — ใช้ Vercel free tier + Google Workspace ที่องค์กรมีอยู่แล้ว + Gemini API free quota สำหรับ scale ปานกลาง

### Q: ขยายไปจังหวัดอื่นได้ไหม?

**A:** ได้ — สถาปัตยกรรม serverless รองรับ multi-tenant โดยแยก Spreadsheet ต่อจังหวัด หรือใช้ sheet เดียวพร้อม column จังหวัด แผน Phase 3 จะ pilot 3 จังหวัดภาคอีสาน

### Q: ต่างจาก Excel ยังไง?

**A:** Excel ต้องพิมพ์เอง + คำนวณเอง + ไม่มี AI + ไม่มีประวัติรวมศูนย์ ระบบนี้ถ่ายรูป BOM → AI อ่าน → คำนวณอัตโนมัติ → บันทึกประวัติ → Export Excel ได้เหมือนเดิม

### Q: ทำไมไม่ใช้ ERP?

**A:** ERP ต้นทุนสูง ใช้เวลา implement นาน ไม่เหมาะกับ pain point ที่ต้องการความเร็วในการประมาณการเบื้องต้น ระบบนี้เสริม ERP ไม่แทนที่ — ให้ราคาเบื้องต้นเร็ว แล้วส่งต่อ ERP เมื่ออนุมัติ

### Q: LINE integration ทำอะไรได้?

**A:** (Phase 3) ลูกค้า CUS ส่งรูป BOM ผ่าน LINE → ระบบประมาณการอัตโนมัติ → ตอบกลับยอดประมาณการในแชท เจ้าหน้าที่ค้นหาโครงการผ่าน LINE ได้
